# not-a-corp.

## Hi

We're two developers, [@Langsch](https://github.com/Langsch) and [@janseealves](https://github.com/janseealves), who like open source and like solving problems. This is where we put the things we build.

## How it started

It began as an idea for a company. Along the way we noticed that what we enjoyed most was the building itself, so for now we're just two devs making open-source projects, to learn and, hopefully, to be useful to other people.

The name is a joke that stuck: nothing here is a company, and each project is named after the big thing it isn't.

## What we like to build

```
  ┌─ Open-source versions of products that are expensive
  ├─ Ideas and niches nobody has tackled yet
  └─ Sometimes just something that looks fun
```

## Join in

Everything here is a work in progress. Issues and pull requests are welcome, in English or Portuguese.
